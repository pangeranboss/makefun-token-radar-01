How to read this board

Implied value is this entry’s own claim, worked out by impliedValue in lib/model.ts from the snapshot alone: TVL × 0.30, times a growth multiplier from the 7-day TVL change (clamped −50% to +150%, weight 0.6), times a maturity multiplier from how long the protocol has run (square-root curve, 0.55 to 1.00 over four years; unknown age counts as one year). A protocol “records no token” when DefiLlama’s record carries no market cap, CoinGecko id or symbol — the record is not proof, so the board never says a protocol has no token.

Coverage. The board holds the whole 40-protocol watchlist (TVL at or above the $50M floor, no token recorded, no wrapped, staked or bridged product) plus every other launch candidate below the floor under the same rule. Protocols whose token already trades are set aside in Already trading, at the market’s own value.

Farm plans are derived from each protocol’s category, chains, TVL and age, and name what each step costs and how long it takes. They are a starting point, not advice: check the protocol’s own pages, never pay to claim anything, and never farm with money you cannot afford to lose.
